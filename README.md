# STUDY TECH

A responsive, bilingual (French / English) learning-platform frontend.

## Current version

The first release contains:
- Responsive homepage for mobile, tablet and desktop
- Navy blue, electric blue and white visual identity
- French / English language switch
- Navigation and learning-category presentation
- Clear notice that member accounts are not active yet

## Run locally

Open `index.html` in a browser. No build step is required.

## Project structure

- `index.html` — page structure and content
- `styles.css` — responsive design system
- `app.js` — language switch and navigation interactions

## Important: backend not connected yet

This is the initial frontend only. Secure registration, login, database storage, student dashboards, course management and administrator tools still need a backend and must be implemented before real users can create accounts or store personal information.

## Deployment

The project can be deployed as a static site through Vercel or another static hosting provider.
